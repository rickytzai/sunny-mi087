# Public repository privacy boundary

This repository contains only the static submission presentation and its public media assets.

Excluded from publication:

- API keys, access tokens, credentials, and environment files
- Raw human audio and plaintext human transcripts
- Private evidence archives
- Machine-specific paths and local operational logs
- Mailbox, messaging, and shared-state data
- Production backend configuration

The human E2E and true barge-in badges describe completed project validation. The private recordings and evidence artifacts are intentionally not published. The animated film is labeled as a visualization and must not be interpreted as literal evidence footage.
