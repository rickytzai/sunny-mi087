# Public repository privacy boundary

This repository contains only the static submission presentation and its public media assets.

Excluded from publication:

- API keys, access tokens, credentials, and environment files
- Raw human audio and plaintext human transcripts
- Private evidence archives
- Machine-specific paths and local operational logs
- Mailbox, messaging, and shared-state data
- Production backend configuration

The human E2E and true barge-in badges describe completed project validation. Public JSON evidence files contain only redacted status, event ordering, evidence identifiers, and claim boundaries. The private recordings and source evidence are intentionally not published.

The event and policy examples are synthetic documentation fixtures. They are not captured telemetry. The animated film is labeled as a scripted product visualization with synthesized dialogue and must not be interpreted as literal evidence footage.

Sunny's public adaptation model is limited to pause tolerance, interruption behavior, response pacing, and turn-taking preference. It does not claim identity, personality, emotion, mental-state, psychological-trait, or biometric inference.
